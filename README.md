# alloyed.io rebuild

Static, pre-rendered rebuild of alloyed.io (Alloyed, formerly SEBPO) built with Astro 5 and Tailwind 4. Every page ships as HTML, so search engines and AI assistants read the full content without running JavaScript.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # outputs dist/
npm run preview
```

Deploy target is Netlify (`netlify.toml`, `public/_redirects`, `public/_headers`). Netlify Forms picks up the contact form automatically (`data-netlify="true"`).

## Where things live

| Path | What |
|---|---|
| `src/data/site.ts` | Navigation, services, industries, case-study summaries, testimonials, leadership, locations, stats, proof points. Edit copy here. |
| `src/data/content/*.json` | Full article bodies scraped from the live site: case studies, perspectives, news, events. |
| `src/data/content.ts` | Typed loaders, markdown rendering, date helpers. |
| `src/layouts/Base.astro` | `<head>`, Organization/WebSite/Breadcrumb JSON-LD, Consent Mode v2 defaults, view transitions, reveal/count-up/tilt scripts. |
| `src/layouts/Article.astro` | Template for perspectives and news. |
| `src/components/` | Header, Footer, HeroGL (WebGL hero), OpsDashboard, ResultsTicker, Comparison, CostCalculator, Timeline, LeadForm, CTA, Consent, MobileCTA, ServiceFAQ, cards. |
| `src/pages/` | Routes. Dynamic routes read from `src/data`. |
| `public/_redirects` | 301 map for old alloyed.io paths and sebpo.com. Deploy the sebpo.com block on that host too. |
| `public/_headers` | CSP, HSTS, frame and MIME protections, immutable caching for fonts and assets. |
| `public/llms.txt` | Generated by `src/pages/llms.txt.ts`. |
| `scripts/` | `og.mjs` renders Open Graph images (`npx tsx scripts/og.mjs` with `astro preview` running), `lh.mjs` Lighthouse, `axe.mjs` accessibility, `links.mjs` internal link check, `shot*.mjs` screenshots. |

## Quality gates

Run with `astro preview` on port 4321:

```bash
node scripts/links.mjs                       # no broken internal links
node scripts/axe.mjs                         # WCAG 2.1 AA, every template
node scripts/lh.mjs http://127.0.0.1:4321/   # Lighthouse mobile + desktop
```

Current: Lighthouse 99–100 mobile / 90 desktop performance, 100 accessibility, 100 best practices, 100 SEO on every template tested.

## Before launch

- Replace placeholder privacy policy and terms text with the approved copy.
- Confirm phone number, email, Calendly link on the thank-you page, and the GTM container ID in `src/components/Consent.astro`.
- Add leadership headshots and any client logos the client approves (components already accept them).
- Submit `sitemap-index.xml` in Search Console and use the Change of Address tool from sebpo.com.
